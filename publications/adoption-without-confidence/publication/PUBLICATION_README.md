# Publication Bundle

This folder contains the public-facing release for the open research note **Adoption Without Confidence?**

## Recommended publishing structure

1. Publish `BLOG_POST.md` as the main readable article.
2. Link the article to the open research note in `../outputs/`.
3. Link the research note to the complete public repository.
4. Use `LAUNCH_KIT.md` for metadata, social copy, figure descriptions, and responses to criticism.
5. Give `EXTERNAL_REVIEW_PACKET.md` to any independent reviewer or replicator.

## Public claims

Use:

> Among current AI-tool users in the 2025 Stack Overflow Developer Survey, favorable stance carried substantially more information about reported daily use than accuracy trust, although the cross-sectional analysis cannot establish which came first.

Avoid:

- “Sentiment causes adoption.”
- “Trust does not matter.”
- “This is the first study to separate trust and sentiment.”
- “The model predicts future AI adoption.”
- “These estimates represent all developers.”

## Included publication formats

- Markdown: source-of-truth blog copy
- HTML: copy-and-paste web version
- DOCX: editable editorial copy
- PDF/DOCX: open research note
- PNG: web-ready figures with supplied alt text
- Markdown: social launch and reviewer materials
